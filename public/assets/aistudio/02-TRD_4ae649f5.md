## 3. Frontend Architecture

### 3.1 Project Structure
```
/src
  /assets           # Static images, icons, fonts
  /components       # Reusable UI components
    /ui             # Base: Button, Input, Card, Modal, Badge
    /layout         # Header, Footer, Sidebar, PageWrapper
    /shared         # SearchBar, NutritionTable, RecipeCard, FoodCard
    /ai             # ChatWidget, MealPlanGenerator, GroceryList
    /admin          # AdminSidebar, DataTable, ContentEditor
  /pages            # One file per route
    /public         # Home, Articles, Recipes, Foods, DietPlans, Search
    /auth           # Login, Signup, ForgotPassword
    /dashboard      # UserDashboard, MealPlanner, Diary, Progress
    /ai             # Chatbot, RecipeGen, GroceryPlanner, PhotoAnalyzer
    /admin          # AdminHome, Articles, Recipes, Users, AI, Analytics
    /dietitian      # Directory, Profile, Booking
  /hooks            # Custom React hooks
  /lib              # API clients, Supabase client, Cloudflare AI client
  /store            # Zustand global state
  /types            # TypeScript interfaces and types
  /utils            # Helper functions, formatters, validators
  /constants        # App-wide constants, config
```

### 3.2 Key Technical Decisions

**Vite + React SPA:**
- All routing client-side via React Router
- Cloudflare Pages handles SPA fallback with `_redirects` file:
  ```
  /* /index.html 200
  ```

**TypeScript:**
- Strict mode enabled
- All API responses typed
- Supabase types auto-generated from schema

**Tailwind CSS:**
- Custom design tokens configured in `tailwind.config.ts`
- No component library dependency (reduces bundle size)
- Custom plugin for nutrition badge colors

### 3.3 Environment Variables (Frontend — Public Only)
```env
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJ...
VITE_CLOUDFLARE_AI_GATEWAY_URL=https://gateway.ai.cloudflare.com/v1/...
VITE_USDA_API_KEY=DEMO_KEY  (public, rate-limited)
VITE_STRIPE_PUBLISHABLE_KEY=pk_live_...
VITE_APP_URL=https://nutriwise.com
```

**Never in frontend:** Supabase service role key, Stripe secret key, AI model API keys.

## 4. Backend / Supabase Architecture

### 4.1 Supabase Services Used

| Service | Usage |
|---|---|
| Supabase Auth | User registration, login, session management, Google OAuth |
| PostgreSQL | All application data |
| Row Level Security (RLS) | Per-table access control |
| Storage | Food images, user-uploaded meal photos, recipe images |
| Edge Functions | Stripe webhooks, email triggers, USDA API proxy |
| Realtime | Optional: live chat for dietitian messaging |

### 4.2 Supabase Auth Configuration
- Email/password signup with email confirmation
- Google OAuth provider enabled
- JWT session tokens (automatic via Supabase)
- Password reset via email
- Role stored in `profiles.role` field (not JWT claims — queried on login)

### 4.3 Supabase Edge Functions

| Function | Trigger | Purpose |
|---|---|---|
| `stripe-webhook` | Stripe POST | Handle subscription events, update user role |
| `send-welcome-email` | User signup | Send welcome email via Resend |
| `usda-proxy` | Frontend fetch | Proxy USDA API calls (hide key, cache results) |
| `ai-meal-plan` | User request | Server-side AI call via Cloudflare AI Gateway |
| `appointment-reminder` | Scheduled | Send appointment reminder emails |

### 4.4 Storage Buckets

| Bucket | Access | Contents |
|---|---|---|
| `food-images` | Public read | Food database item images |
| `recipe-images` | Public read | Recipe cover photos |
| `user-uploads` | Private (owner only) | Meal photos for food diary |
| `dietitian-documents` | Private (owner + admin) | Client intake forms, plan uploads |
| `article-images` | Public read | Blog article header images |

## 5. AI Services Architecture

### 5.1 Cloudflare AI Gateway Setup

All AI calls route through Cloudflare AI Gateway:
- API keys stored in Cloudflare Workers secrets (never in frontend)
- Rate limiting per user enforced at gateway level
- Request/response logging for quality review
- Fallback model configuration

**Gateway URL pattern:**
```
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_name}/
```

### 5.2 AI Models (Cloudflare Workers AI — Free Tier)

| Use Case | Model | Notes |
|---|---|---|
| Nutrition Chatbot | @cf/meta/llama-3.1-8b-instruct | Fast responses, good instruction following |
| Meal Plan Generator | @cf/mistral/mistral-7b-instruct-v0.1 | Structured JSON output |
| Recipe Generator | @cf/meta/llama-3.1-8b-instruct | Creative recipe suggestions |
| Photo Analyzer | @cf/llava-hf/llava-1.5-7b-hf | Vision model for food photos |
| Label Scanner | @cf/llava-hf/llava-1.5-7b-hf | Vision model for label images |

### 5.3 AI Request Flow

```
User Action (Browser)
      │
      ▼
Supabase Edge Function OR Cloudflare Worker
      │  (validates session, checks quota)
      ▼
Cloudflare AI Gateway
      │  (rate limiting, logging)
      ▼
Workers AI Model
      │
      ▼
Structured Response → Frontend
```

### 5.4 AI Safety Rules (Enforced in System Prompts)
- Refuse to diagnose, prescribe, or treat medical conditions
- Always recommend professional consultation for: pregnancy, eating disorders, serious allergies, medications
- Emergency symptoms → provide emergency contact guidance only
- All nutrition claims cite general dietary guidance
- Output always includes: "This is general wellness information, not medical advice."

### 5.5 AI Usage Limits

| User Type | Chatbot | Meal Plan | Recipe Gen | Photo/Label |
|---|---|---|---|---|
| Guest | 2/day | 0 | 0 | 0 |
| Free Member | 5/day | 1/month | 3/day | 0 |
| Premium Member | Unlimited | Unlimited | Unlimited | 10/day |

Quota tracked in `ai_usage_logs` table. Enforced in Edge Function before AI call.

## 6. External API Integrations

### 6.1 USDA FoodData Central API
- **URL:** `https://api.nal.usda.gov/fdc/v1/`
- **Auth:** API key (free, register at fdc.nal.usda.gov)
- **Key endpoints:**
  - `GET /foods/search` — search foods
  - `GET /food/{fdcId}` — get full nutrition data
- **Caching:** Results cached in Supabase `foods` table to reduce API calls
- **Proxy:** All calls via Supabase Edge Function `usda-proxy`

### 6.2 Stripe
- **Subscription management:** Monthly/annual premium plans
- **Payments:** Consultation booking payments
- **Webhooks:** `stripe-webhook` Edge Function handles:
  - `customer.subscription.created` → upgrade user to premium
  - `customer.subscription.deleted` → downgrade to free
  - `invoice.payment_failed` → send payment failure email
- **Keys:** Secret key in Supabase Edge Function secrets only

### 6.3 Resend (Email)
- **Templates:** Welcome, password reset, appointment reminder, weekly newsletter
- **API key:** Stored in Edge Function secrets
- **From domain:** hello@nutriwise.com (custom domain required)

## 7. SEO Technical Requirements

- **Structured Data:** Recipe schema, Article schema, BreadcrumbList — injected via React Helmet Async
- **Meta tags:** Dynamic per page via React Helmet Async
- **XML Sitemap:** Auto-generated, submitted to Google Search Console
- **Robots.txt:** Block admin, auth, dashboard pages
- **Canonical URLs:** Set on all pages
- **URL Structure:**
  - Articles: `/articles/[slug]`
  - Recipes: `/recipes/[slug]`
  - Foods: `/foods/[food-name]`
  - Diet Plans: `/diet-plans/[plan-slug]`
- **Image optimization:** WebP format, lazy loading, descriptive alt text
- **Core Web Vitals:** LCP < 2.5s, FID < 100ms, CLS < 0.1

## 8. Security Requirements

| Requirement | Implementation |
|---|---|
| HTTPS only | Cloudflare enforces HTTPS |
| API keys hidden | Edge Functions + Cloudflare Workers secrets |
| SQL injection prevention | Supabase parameterized queries |
| XSS prevention | React escapes by default; no dangerouslySetInnerHTML |
| CSRF protection | Supabase handles via JWT |
| Rate limiting | Cloudflare WAF + AI Gateway rate limiting |
| Row Level Security | RLS enabled on all Supabase tables |
| File upload validation | Type, size, virus scan before storage |
| Admin access | Role-based, separate admin route guard |
| Audit logs | Admin actions logged to `audit_logs` table |
| Data encryption | Supabase encrypts at rest; HTTPS in transit |
